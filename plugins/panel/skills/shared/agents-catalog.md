# Agent Knowledge Base
Source: https://github.com/VoltAgent/awesome-claude-code-subagents

Use this as a **library of expertise concepts** to synthesize from — not a menu to pick from.
When building a synthesized agent, identify which catalog domains cover the expertise cluster you need and blend them into a single task-specific agent definition.

Install any catalog agent with: `claude agent add VoltAgent/awesome-claude-code-subagents/<name>`
